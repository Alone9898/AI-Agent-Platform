核心能力围绕真实工作流组织

星曜不是只放一个聊天框，而是把 Agent 的配置、技能、模型、运行过程和本地桌面能力拆清楚，方便你持续维护。

Agent 管理

配置 Agent 名称、描述、系统提示词，并绑定合适的模型与技能，让每个 Agent 的职责清楚可查。

Skill 技能库

支持 prompt、tool、mixed 三类 Skill，内置分页、搜索、过滤和预置技能导入，适合后续扩展。

Model 配置

管理厂商预设和自定义模型参数，使用 OpenAI 兼容接口，把 API Key、Base URL 和模型标识集中维护。

工具执行

当前已接入时间、计算器、联网搜索、网页读取和 HTTP GET 请求，工具是否可用由 Agent 绑定的 Skill 决定。

从配置到对话，路径尽量短

日常使用可以按三个步骤走。先让模型能连上，再让 Agent 有明确职责，最后在对话里调用需要的工具。

01

配置 Model

填写模型标识、Base URL 和 API Key。平台会把模型配置作为 Agent Runtime 的调用来源。

02

组装 Agent

写清系统提示词，选择模型，绑定一个或多个 Skill。工具类 Skill 会转换为模型可调用的 function tools。

03

开始对话

对话会保存 conversationId、消息上下文和执行步骤。需要联网、读取网页或计算时，由运行时按需调工具。

为本地桌面环境准备

项目基于 Tauri 2、Vue 3、NestJS、Prisma 和 SQLite。前端、后端服务、本地数据和桌面壳能力放在同一个产品边界里。

SQLite 本地数据存储，登录态、Agent、Skill、Model 和会话记录由后端统一管理。
桌面端支持系统托盘、单实例运行、关闭隐藏到托盘，并通过 sidecar 拉起 NestJS 服务。
工具能力有明确边界，高权限写文件和执行代码类能力没有默认开放，后续可按白名单和审计继续接入。

发布前常见问题

这部分文字保持朴素，方便你后面直接换成正式说明、价格、更新日志或隐私政策。

是否需要后端服务地址？

桌面端通过 sidecar 拉起本地 NestJS 服务，用户正常使用不需要手动填写动态后端地址。

联网搜索为什么有时不可用？

联网搜索依赖 Tavily API Key。没有配置时，Agent 应该明确说明当前工具不可用。

数据放在哪里？

应用使用 SQLite 保存本地数据。具体数据库位置由 Tauri 应用数据目录和后端启动参数决定。
